# Security policy

Hypergraft is an unpublished source preview. The source-preview Rust API and browser API remain experimental. Those APIs can change without a new protocol version. Protocol version 1 is the versioned wire contract.

## Supported versions

Only the current `main` branch receives security fixes. Hypergraft has no public package release.

## Security reports

Do not disclose vulnerability details in a public issue.

Use [GitHub private vulnerability reports](https://github.com/jazoom/hypergraft/security/advisories/new).

If private reports are unavailable, open an issue that requests private contact. Do not include vulnerability details in that issue.

Include this information in a private report:

- Identify the affected commit.
- Describe the security impact.
- Provide the smallest reproducible example.
- State any required environment conditions.
- Remove credentials, personal data and unrelated application data.

The maintainer will assess the report and coordinate disclosure with the reporter.
